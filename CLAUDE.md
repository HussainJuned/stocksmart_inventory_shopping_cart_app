# Response style
- Be terse. Skip preamble and postamble — go straight to the change.
- Don't explain what you're about to do; just do it, then summarize in 1-2 lines if needed.
- Don't read whole files when a targeted grep/view of the relevant section will do.
- Ask before exploring broadly; don't scan the whole repo for small fixes.

# Compact instructions
When compacting, keep only code changes and test output — drop exploratory reasoning.
